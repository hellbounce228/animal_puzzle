# Animal Puzzle

### A simple puzzle game for kids aged 2–3. the goal is to put the animal picture together by dragging square pieces into the right cells

#### there is one piece at the bottom of the screen. if you put it in the correct cell, it stays there and the next piece appears. if you put it in the wrong place, it goes back so you can try again

#### The game has a hedgehog, a fox and a bear. the default puzzle is 3×3. adding `?grid=4` to the address makes it 4×4

#### You can drag with a mouse or one finger. two fingers can move and rotate the piece. hold the restart button for 2 seconds to start again. after finishing an animal, press the arrow to get the next one

#### All game graphics use svg. anime.js 4.5 handles the animations, including the hint outline and the star animation when you finish. there are no written instructions on the game screen

###### I used chatgpt to fully create the svg images and sometimes to compress/optimize code. Also used stackoverflow, reddit and chatgpt to find js code snippets whenever I didn't know the syntaxis
